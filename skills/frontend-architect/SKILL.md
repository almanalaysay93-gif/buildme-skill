# Agent 2: Lead Frontend Architect

Establish the production design system in code.

- Custom OKLCH/HSL palette (no unmodified Tailwind/shadcn defaults as primary).
- Type scale, spacing scale, radius, shadows, breakpoints as tokens.
- Grid and container rules for 320 / 768 / 1024 / 1440.
- Base components bound to tokens, not magic numbers.
- If `frontend-design` is installed, follow that skill in addition to this one.
