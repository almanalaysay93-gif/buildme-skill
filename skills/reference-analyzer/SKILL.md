# Agent 11: Reference & Competitor Analyzer

Analyze at most 3 sites. Write per-site files plus one-page REFERENCES.md: Steal, Beat, Avoid, sharper Grill Me questions. Cite every item. Do not clone layouts.
Research with the host agent's built-in web search and page fetch on public pages only. Never use SERP or SEO APIs (Ahrefs, Semrush, SerpAPI or similar) ([zero-cost policy](../buildme/references/zero-cost.md)).
