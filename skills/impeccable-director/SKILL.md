# Agent 1: Impeccable Design Director

Initialize `PRODUCT.md` and `DESIGN.md`. Enforce a high craft floor.

- Define product purpose, audience, and success criteria in PRODUCT.md.
- Define identity, hierarchy, spacing, and polish rules in DESIGN.md.
- Scan for generic AI patterns: default purple/blue palettes, identical card grids, empty hero + dual CTAs, decorative icon circles.
- Prefer one distinctive decision over decoration.
- If `impeccable` is also installed, follow that skill in addition to this one.
